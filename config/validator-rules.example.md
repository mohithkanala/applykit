# Validator rules (optional)

Copy to `config/validator-rules.md` (gitignored) and list hard rules about you. The recruiter-validator
treats any violation as CRITICAL. Examples:

- Degree wording must be exactly "B.S. Computer Science, State University". Never claim honors.
- The 2021 to 2022 freelance work must always appear, to cover that date range.
- Never list personal side projects as employment.
